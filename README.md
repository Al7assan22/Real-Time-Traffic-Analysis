# 🚦 Real-Time Traffic Analytics & Smart Monitoring System

An end-to-end real-time traffic analytics system built with Python and Azure Event Hubs.

The project simulates live traffic data, sends the data through Azure Event Hubs, consumes and processes the incoming events using Python, and displays real-time traffic insights through an interactive Streamlit dashboard.

---

## 🏗️ System Architecture

```text
Traffic Generator
       ↓
Azure Event Hub
       ↓
Python Event Consumer
       ↓
Pandas Data Processing
       ↓
Streamlit Dashboard
       ↓
Real-Time Traffic Analytics
```

---

## 🔄 How It Works

### 1. Traffic Data Generator

`traffic_generator.py` generates simulated traffic events continuously.

Each event contains information such as:

* Vehicle ID
* Speed
* Location
* Timestamp

The generated events are sent to Azure Event Hubs.

### 2. Azure Event Hubs

Azure Event Hubs is used as the real-time event streaming layer.

It receives the traffic events generated by the Python producer and makes them available for consumption.

### 3. Python Event Consumer

`app.py` uses the Azure Event Hubs Python SDK to consume incoming traffic events.

The received data is processed in Python and stored temporarily for real-time analysis.

### 4. Real-Time Analytics

The project uses Pandas to process the incoming traffic data and calculate metrics such as:

* Average Speed
* Minimum Speed
* Maximum Speed
* Number of Vehicles
* Traffic by Road
* Speed Violations
* Recent Vehicle Activity

### 5. Streamlit Dashboard

The processed data is displayed through an interactive Streamlit dashboard.

The dashboard provides:

* Current Vehicle Status
* Real-Time Traffic Overview
* Speed Trend
* Traffic by Road
* Live Speed Gauge
* Normal vs Warning Vehicles
* Speed Distribution
* Average Speed by Road
* Top Fastest Vehicles
* Recent Violations
* Recent Vehicles Table

The dashboard automatically refreshes to display newly received traffic events.

## 🚀 Running the Project

### 1. Install the required packages

```bash
pip install -r requirements.txt
```

### 2. Configure Azure Event Hubs

Create a `.streamlit/secrets.toml` file and add your Azure Event Hubs connection string:

```toml
EVENT_HUB_CONNECTION_STR = "YOUR_CONNECTION_STRING"
```

> Never commit your `secrets.toml` file or Azure connection string to GitHub.

### 3. Start the Traffic Generator

Open a terminal and run:

```bash
python traffic_generator.py
```

The script will continuously generate and send traffic events to Azure Event Hubs.

### 4. Start the Streamlit Dashboard

Open another terminal and run:

```bash
streamlit run app.py
```

The Streamlit dashboard will start receiving and displaying the incoming traffic data.
